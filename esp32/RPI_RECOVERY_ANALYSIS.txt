The Raspberry Pi rpi_snap.py system successfully implements robust frame storage recovery that preserves all critical violation evidence even during system failures or network outages. The system operates by continuously capturing frames from the Pi camera, running Hailo AI inference for smoke, vehicle, and license plate detection, and automatically saving annotated frames to local storage at /home/sevi/video_pi/ whenever any detection occurs. Each saved frame includes colored detection boxes (red for smoke with opacity levels, green for vehicles with class names, yellow for license plates with OCR text), timestamped filenames with detection counts in the format like "2026-03-28T04-15-32_S1_V1_P1.jpg", and complete visual context including violation borders when both smoke and vehicle are detected simultaneously. The frame saving process runs in a background thread pool with four workers to ensure the main inference loop continues uninterrupted, using 90% JPEG compression for storage efficiency while maintaining image quality for evidence purposes.

While the system has limitations in terms of HTTP POST failure recovery where detection metadata can be lost if the backend is unreachable, and lacks retry mechanisms for failed API calls or automatic recovery from camera and Hailo hardware failures, the most critical recovery mechanism works flawlessly. The persistent local storage of annotated detection frames ensures that no violation evidence is permanently lost, making it possible to manually review and recover all detection events even after extended backend downtime, network failures, program crashes, or power outages. This approach provides significantly better resilience compared to systems without local storage, as the visual evidence containing all necessary information for violation verification and enforcement action remains accessible on disk regardless of external system failures.

The recovery system's effectiveness lies in its ability to maintain complete visual documentation of the detection process, with each frame serving as a comprehensive record that includes the original camera image, AI detection results overlaid as colored bounding boxes, opacity analysis for smoke detections, OCR results for license plates, timestamp information, and detection statistics. This ensures that even if the real-time data transmission to the backend fails, the essential evidence for regulatory compliance and violation enforcement is preserved locally, making the RPi system a reliable solution for continuous monitoring applications where data integrity and evidence preservation are critical requirements.
